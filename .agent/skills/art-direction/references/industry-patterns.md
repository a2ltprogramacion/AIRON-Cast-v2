# Industry-Specific Visual Strategies

Sector-specific visual patterns with **psychological reasoning** behind each decision. Load when generating images for a specific client industry.

---

## 1. Technology / IT Consulting / SaaS

**Visual Goals:** Innovation, reliability, precision, speed, connectivity.

| Element         | Recommendation                                                                               |
| --------------- | -------------------------------------------------------------------------------------------- |
| **Style**       | Isometric 3D, cinematic, glassmorphism, abstract geometric, clean wireframes                 |
| **Colors**      | Blues (trust), grays (neutral), accents of neon (innovation). Avoid muddy browns             |
| **Lighting**    | Studio soft light with rim highlights; volumetric god rays for "cloud" concepts              |
| **Subjects**    | Floating UI elements, circuit patterns, data streams, interconnected nodes, abstract servers |
| **Composition** | Asymmetric with leading lines; depth through layered elements                                |

**Psychological Reasoning:**

- Blue evokes trust and stability — the most common color in tech for this reason.
- Isometric views suggest systematic thinking and order.
- Clean lines imply precision and reliability.
- Neon accents signal cutting-edge innovation without overwhelming the composition.

❌ **Anti-Patterns:** Overly complex diagrams (confusing), dark muddy backgrounds (dated), generic office scenes with computers (cliché), cartoonish robots (undermines seriousness), "hand touching hologram."

## 2. Healthcare / Wellness / Pharma

**Visual Goals:** Compassion, trust, cleanliness, hope, scientific rigor.

| Element         | Recommendation                                                                     |
| --------------- | ---------------------------------------------------------------------------------- |
| **Style**       | Soft focus photography, watercolor illustrations, gentle gradients, organic shapes |
| **Colors**      | Whites, blues, greens (calm), soft lavenders (care). Avoid reds (danger signal)    |
| **Lighting**    | Diffused, bright, shadowless (clinical feel); warm window light for wellness       |
| **Subjects**    | Abstract DNA helixes, stylized medical symbols, organic forms, leaves for wellness |
| **Composition** | Symmetrical for trust, curved lines for comfort                                    |

**Psychological Reasoning:**

- White and blue convey cleanliness and sterility — foundational trust signals in healthcare.
- Soft lighting reduces anxiety in patients/visitors.
- Organic shapes feel natural and healing — they counterbalance clinical sterility.
- Abstract symbols avoid literal medical imagery that might trigger fear.

❌ **Anti-Patterns:** Stethoscopes/syringes/blood (too clinical, frightening), overly technical diagrams (alienating), dark shadows (ominous), realistic surgery scenes.

## 3. Legal / Finance / Consulting

**Visual Goals:** Authority, trust, tradition, clarity, protection.

| Element         | Recommendation                                                                           |
| --------------- | ---------------------------------------------------------------------------------------- |
| **Style**       | Architectural visualization, editorial photography, minimalist, gold accents             |
| **Colors**      | Navy blue, burgundy, gold, cream, dark wood tones. Avoid bright neons                    |
| **Lighting**    | Moody chiaroscuro (courtroom drama), warm library light                                  |
| **Subjects**    | Columns, scales of justice (stylized), law books, geometric structures, abstract balance |
| **Composition** | Symmetrical tension, sharp diagonals, strong perspectives                                |

**Psychological Reasoning:**

- Dark blues and burgundies evoke tradition and authority — centuries of association.
- Gold accents suggest prestige and premium value.
- Symmetry implies balance and fairness — core legal values.
- Architectural elements convey permanence and stability.

❌ **Anti-Patterns:** Clichéd handcuffs or judges (too literal), modern casual settings (undermines gravitas), blue-suit portraits on white (generic), bright playful colors.

## 4. Food / Hospitality / Beverage

**Visual Goals:** Appetizing, fresh, authentic, indulgent, artisanal.

| Element         | Recommendation                                                                            |
| --------------- | ----------------------------------------------------------------------------------------- |
| **Style**       | Macro photography, editorial, retro vintage, rustic textures                              |
| **Colors**      | Warm reds (appetite), greens (fresh), browns (earthy), creams (comfort). Avoid cold blues |
| **Lighting**    | Golden hour, natural window light, dramatic backlighting, spot on hero dish               |
| **Subjects**    | Fresh ingredients, steam rising, abstract shapes of food, textures, atmospheric interiors |
| **Composition** | Macro close-ups, bird's eye tablescapes, asymmetric arrangement, rule of thirds           |

**Psychological Reasoning:**

- Red stimulates appetite (increases heart rate) — used by 70%+ of food brands.
- Warm tones evoke comfort and homeliness — triggers nostalgia.
- Macro shots create intimacy with food — viewer "enters" the dish.
- Steam suggests freshness and warmth — temperature is a powerful appetite trigger.

❌ **Anti-Patterns:** Over-processed food (unappetizing), dirty/messy plating, generic stock burgers, unnatural colors (blue meat), oversaturated HDR.

## 5. Fitness / Sports

**Visual Goals:** Energy, strength, determination, health, community.

| Element         | Recommendation                                                               |
| --------------- | ---------------------------------------------------------------------------- |
| **Style**       | Dynamic photography, bold geometric patterns, gritty textures, high-contrast |
| **Colors**      | Orange (energy), black (power), white (clean), neon accents. Avoid pastels   |
| **Lighting**    | Hard directional light (gym spot), dramatic backlight, dramatic rim          |
| **Subjects**    | Abstract human movement, weights, geometric shapes in motion, speed lines    |
| **Composition** | Diagonal lines, off-balance, dynamic cropping, low angle (power)             |

**Psychological Reasoning:**

- Orange and reds increase energy and urgency — physiological arousal.
- Diagonal lines suggest movement and effort — the brain reads them as unstable/dynamic.
- High contrast evokes determination and grit.
- Abstract movement avoids unrealistic body standards while conveying action.

❌ **Anti-Patterns:** Perfect airbrushed models (unrealistic, alienating), empty gyms (lonely), clichéd protein shake photos, static poses (boring), "person doing bicep curl" stock.

## 6. Real Estate / Architecture

**Visual Goals:** Aspirational, spacious, warm, inviting, trustworthy.

| Element         | Recommendation                                                                        |
| --------------- | ------------------------------------------------------------------------------------- |
| **Style**       | Architectural visualization, editorial photography, tilt-shift, minimalist            |
| **Colors**      | Earth tones, warm neutrals, sky blues, greenery. Avoid garish colors                  |
| **Lighting**    | Natural daylight (golden hour), soft interior ambience, pool reflections              |
| **Subjects**    | Dramatic perspectives (hallways, staircases), material textures, building silhouettes |
| **Composition** | Wide angle, leading lines, vanishing points, symmetrical facades                      |

**Psychological Reasoning:**

- Warm neutrals feel homey and inviting — reduce buyer anxiety.
- Wide angles suggest spaciousness — the #1 desire in property search.
- Natural light evokes openness and honesty.
- Greenery connects to outdoor living — increases perceived property value.

❌ **Anti-Patterns:** Cluttered rooms (messy feeling), overcast gloomy skies (depressing), fish-eye distortion, HDR overdose, empty unstaged rooms.

## 7. Education / E-Learning

**Visual Goals:** Curiosity, growth, clarity, inclusivity, inspiration.

| Element         | Recommendation                                                                       |
| --------------- | ------------------------------------------------------------------------------------ |
| **Style**       | Flat vector illustration, line art, friendly 3D characters, papercut                 |
| **Colors**      | Warm yellows (optimism), blues (trust), greens (growth). Avoid dark oppressive tones |
| **Lighting**    | Bright, even; soft glow for e-learning screens                                       |
| **Subjects**    | Books (abstracted), interconnected nodes, growth metaphors, diverse abstract figures |
| **Composition** | Circular layouts (community), ascending lines (progress), open spaces                |

**Psychological Reasoning:**

- Yellow stimulates mental activity and optimism — proven in learning environments.
- Circular shapes suggest community and inclusion — no hierarchy implied.
- Bright colors create a welcoming environment — reduces learning anxiety.
- Abstract figures avoid stereotyping and increase inclusivity.

❌ **Anti-Patterns:** Traditional chalkboards (dated), solitary figures (isolating), overly complex diagrams, dull institutional colors, childish illustrations for adult audiences.

## 8. Creative Agency / Marketing

**Visual Goals:** Creativity, boldness, uniqueness, collaboration, edge.

| Element         | Recommendation                                                                    |
| --------------- | --------------------------------------------------------------------------------- |
| **Style**       | Mixed media collage, abstract expressionism, surrealism, bold typography as image |
| **Colors**      | Unexpected combinations (coral+navy, acid green+black). Avoid corporate defaults  |
| **Lighting**    | Dramatic, experimental, colored gels, neon                                        |
| **Subjects**    | Abstract shapes overlapping, paint strokes, geometric chaos, surreal compositions |
| **Composition** | Extreme asymmetry, deconstructed, layered, rule-breaking                          |

**Psychological Reasoning:**

- Unexpected colors signal creativity and non-conformity — the agency IS the product.
- Collage suggests multidisciplinary approach and breadth.
- Layering implies depth and complexity of thinking.
- Rule-breaking compositions show boldness — conformity is the enemy.

❌ **Anti-Patterns:** Safe corporate designs (boring), clichéd "creative" imagery (paintbrushes, color swatches), overly neat compositions (lack of edge), people brainstorming around whiteboard.

## 9. GoHighLevel / CRM / Marketing Automation

**Visual Goals:** Efficiency, connection, growth, modernity, data-driven.

| Element         | Recommendation                                                              |
| --------------- | --------------------------------------------------------------------------- |
| **Style**       | Clean isometric 3D, flat vector with data elements, futuristic UI-inspired  |
| **Colors**      | Brand-aligned, blues + whites, tech-neutral grays, neon accents             |
| **Lighting**    | Soft studio with glow effects on data points                                |
| **Subjects**    | Abstract dashboards, connected nodes, automation flows, pipeline metaphors  |
| **Composition** | Grid-based, structured, with dynamic data visualization, left-to-right flow |

**Psychological Reasoning:**

- Connected nodes represent integration and automation — core platform value.
- Data visualizations convey insights and control — what users want.
- Clean layouts suggest efficiency — no wasted space, no wasted effort.
- Grid structure mirrors the structured nature of CRM data.

❌ **Anti-Patterns:** Generic office scenes (no differentiation), cluttered charts (confusing), static unconnected elements, overused "funnel" diagrams, overly playful illustrations.
