# Prompt Anatomy: The 8-Block Visual Prompt Architecture

Deep reference for composing high-quality image generation prompts. Load this file when crafting complex prompts or when the 5-Pillar summary in SKILL.md needs expanded vocabulary.

---

## The 8-Block Structure

```
[1.Subject] [2.Style] [3.Medium] [4.Composition] [5.Lighting] [6.Color] [7.Technical] [8.Negatives]
```

## Block 7: Technical Specs

**Aspect Ratios by Asset Type:**

| Asset Type           | Ratio        | Prompt Keyword               |
| -------------------- | ------------ | ---------------------------- |
| Hero Background      | 16:9 or 21:9 | "wide 16:9 aspect ratio"     |
| Service Illustration | 1:1 or 4:3   | "square format" or "4:3"     |
| Avatar               | 1:1          | "square portrait format"     |
| Logo                 | 1:1          | "square format"              |
| OG Image             | ~1.91:1      | "ultra-wide banner 1200x630" |
| Texture              | 1:1          | "seamless tileable square"   |
| Before/After         | 16:9 or 2:1  | "wide split composition"     |
| Product              | 4:3          | "product shot format"        |
| Infographic          | 2:1          | "landscape data visual"      |

**Resolution Hints:** `high detail, 8k` (hero), `sharp, 4k` (product), `crisp vector lines` (illustration).

**Guidance Scale:** Default 7.5 (balanced). Strict brand: 9-10. Creative exploration: 5-6.

## Block 8: Negative Prompts

**Universal (ALWAYS include):**

```
no text, no letters, no words, no numbers, no watermark, no signature, no border, no frame,
no blurry, no distorted, no deformed, no low quality, no pixelated, no ugly,
no clichés, no handshake, no stethoscope, no headset, no lightbulb, no puzzle piece, no rocket
```

**Context-Specific Additions:**

| Context        | Add to Negatives                                                                          |
| -------------- | ----------------------------------------------------------------------------------------- |
| Photorealistic | `no cartoon, no illustration, no painting, no 3D render, no CGI`                          |
| Illustrations  | `no photograph, no realistic, no photo`                                                   |
| Logos          | `no complex background, no intricate details, no photorealistic`                          |
| Textures       | `no objects, no subjects, no foreground, no depth, no focal point`                        |
| Human Figures  | `no extra fingers, no deformed face, no unnatural pose, no mannequin, no asymmetric eyes` |
| Abstract       | `no recognizable objects, no literal interpretation`                                      |
| Backgrounds    | `no distracting elements, no competing focal points`                                      |

## Iterative Refinement Technique

If a generated image fails quality gates, refine using this loop:

1. **Adjust guidance scale** — increase for stricter prompt adherence, decrease for creativity.
2. **Add specific negative prompts** — target the exact unwanted element.
3. **Strengthen subject description** — more adjectives, relationships, spatial context.
4. **Change lighting or composition** — if mood is off, lighting is the fastest fix.
5. **Simplify color palette** — if chaotic, reduce to 2-3 colors max.
6. **Try a different style** — if medium doesn't match brand, switch entire style directive.
